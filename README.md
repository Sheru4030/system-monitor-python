Repository Overview

This project is hosted on GitHub and demonstrates the use of version control and collaborative development practices.

Project Files
- monitor.py – Main Python script that monitors CPU, memory, and disk usage.
- system.log – Log file that stores recorded system metrics for monitoring and troubleshooting.
- README.md – Documentation explaining the project, setup, and usage.

Key Concepts Demonstrated

Version Control
- The project uses Git for version control to track changes in the source code.
- Each change is committed with descriptive messages to maintain a clear development history.

Repository Management
- The project repository is maintained on GitHub for centralized code storage and access.
- Code updates can be pushed to the repository and accessed from different environments.

Code Collaboration
- Hosting the project on GitHub allows multiple developers to contribute to the project.
- Contributors can clone the repository, create branches, submit pull requests, and review code changes.
